# Security policy

## Supported versions

This package is pre-1.0. Only the latest release gets security fixes.

| Version | Supported |
| ------- | --------- |
| 0.9.x   | Yes       |
| < 0.9   | No        |

## Report a vulnerability

Do not open a public issue.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/parisek/acf-json-schema/security) of the repository.
2. Click "Report a vulnerability".

Direct link: <https://github.com/parisek/acf-json-schema/security/advisories/new>

We aim to reply within 7 days.

## What to include

- The affected version.
- The steps to reproduce the problem.
- The impact, as you see it.

## What happens next

We confirm the problem and work on a fix with you in private. A fix ships as a patch release with a GitHub Security Advisory.
